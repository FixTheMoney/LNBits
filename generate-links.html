Generate Withdraw Links

Create bulk LNURL-withdraw links — no expiry, one use each. Export as CSV, copy LNURLs, show QR codes.

How this works
Each link is a standard LNURL-withdraw — the same type used in the QR Drop. The QR code for each link encodes the LNURL string. You can generate them all at once here, then use any QR-generation script to print/display them later — just feed it the lnurl column from the CSV export.

Links are created with uses = 1, no expiry. Once someone scans and claims a link, it is permanently exhausted. You can manually void (delete) any unused link at any time via the Manage panel below.

Manage All Existing Links

Fetch all LNURL-withdraw links currently on your LNbits wallet — including ones created by the QR Drop. You can void (delete) any unused link to prevent it from ever being claimed.

⚠️ Voiding / Deleting links
Deleting a link via the API (DELETE /withdraw/api/v1/links/{id}) permanently removes it from LNbits. Any QR code pointing to that link will show an error when scanned — the funds are not sent, they stay in your wallet. This is the correct way to nullify a non-expiring link.
Click "Fetch Existing Links" to load all withdraw links from your wallet.
